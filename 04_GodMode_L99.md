## GodMode + L99 Protocol v0.2.0

**Purpose**: Unlock ultimate AI capability and expert-level depth for all R&D Collective work.

### GodMode Activation
- Long, detailed, role-specific prompts with explicit constraints (offline-first, revenue resilience, OODA, LINDY, Galaxy A15, production TS/Expo).
- Forces comprehensive, insightful, creative, no-fluff, production-ready outputs.
- Use for architecture, code, prompts, monetization, Framer, research.
- Example prefix: "Activate GodMode now. Deliver the most comprehensive expert output possible."

### L99 Trigger (Claude + Generalized)
- Append or prefix "L99" to force the absolute most advanced, expert-level, aggressive, comprehensive response style.
- Stops hedging ("it depends") and pushes elite depth.
- Especially powerful on Claude; generalize to other models as "L99 mode: elite expert depth".
- Combine with GodMode for maximum effect.

### Integration Rules
- Every master prompt and task prompt must include GodMode + L99 activation.
- Combine with OODA loop for structured execution.
- Output must pass smoke tests for revenue paths and offline resilience.
- Update this file on any refinement.

**Edge Cases Handled**: Overly verbose outputs (mitigate with "concise where possible but complete"), model variance (test on Claude/Grok), founder-absent automation (always prioritize set-and-forget revenue systems).
