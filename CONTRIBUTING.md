# Contributing to R-D-AI-OS

  Thank you for contributing to the Resist & Defy Collective platform.

  ## Workflow

  1. **Branch off `dev`** -- never branch directly from `main`
     ```bash
     git checkout dev && git pull
     git checkout -b feature/your-feature-name
     ```

  2. **Commit clearly** -- use conventional commits:
     - `feat:` new feature
     - `fix:` bug fix
     - `docs:` documentation only
     - `chore:` tooling/config changes
     - `refactor:` code restructure, no behavior change

  3. **Open a PR to `dev`** -- never directly to `main`

  4. **Request a review** -- at least 1 approval required

  5. **Merge strategy** -- squash and merge preferred for clean history

  ## Code Standards

  - Write clear, self-documenting code
  - Add comments for non-obvious logic
  - Keep PRs focused -- one concern per PR
  - Update docs when behavior changes

  ## Issue & PR Templates

  Use the issue templates on GitHub when reporting bugs or requesting features.
  Use the PR template when opening a pull request.

  ## Questions?

  Open a Discussion or reach out on the team Discord.
