# gstack (Core Engineering Layer)

Use gstack for all product, engineering, design, QA, and shipping work.
Prefer gstack’s `/browse` for every web task. Never use mcp__claude-in-chrome__* tools.

Primary workflow for any new app or feature:

1. `/office-hours` or `/plan-ceo-review` → validate the money angle first
2. `/plan-eng-review`                  → architecture
3. `/design-consultation` or `/design-shotgun` → UI
4. `/review` + `/qa`                   → quality gate
5. `/ship` or `/land-and-deploy`       → go live
